Scenario Inputs let you define a structured set of data that can be passed into a scenario each time it runs.

### **🔹 What Are Scenario Outputs?**

Scenario Outputs allow you to return results or statuses from a scenario using the Return module.

* These are the "results" a scenario sends back to the parent scenario or application.  
* Examples: confirmation messages, new account credentials, task statuses, etc.

Using inputs and outputs allows you to:

* ✅ Modularize complex automations
